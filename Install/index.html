Installing Snèh AI

Snèh AI is a Progressive Web Application (PWA). You can install it directly onto your device without using an app store.

Apple iOS (iPhone & iPad)

  1. Open Safari and navigate to https://snehai.netlify.app/.
  2. Tap the Share button at the bottom of your browser screen.
  3. Scroll down and tap Add to Home Screen.
  4. Confirm by tapping Add in the top right corner.

Android (Google Chrome & Edge)

  1. Open Chrome and go to https://snehai.netlify.app/.
  2. Tap the three vertical dots menu in the top right corner.
  3. Select Install app or Add to Home screen.
  4. Follow the on-screen prompt to complete setup.

Windows & Mac Desktop

  1. Visit https://snehai.netlify.app/ in Chrome or Brave browser.
  2. Look for the Install Snèh AI icon inside the address bar.
  3. Click Install to launch Snèh AI as an independent desktop window.
