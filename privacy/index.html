Snèh AI Privacy Architecture

Published by DBC Technologies (DBC Technologies Narwana) | Official Data Policy

1. Ephemeral Volatile Memory Processing

Messages processed through Snèh AI exist temporarily in volatile server RAM only during token generation. As soon as the AI stream closes, session memory buffers are wiped.

2. No AI Model Training

We strictly enforce zero-retention commercial API policies. Your personal questions, code snippets, and uploaded files are never saved or harvested to train public language models.

3. Regulatory Standards & Jurisdiction

Hosted on the Narwana Cloud Grid in District Jind, Haryana (India), Snèh AI operates in strict compliance with India's Digital Personal Data Protection (DPDP) Act 2023.

4. Optional Incognito Mode

Activate Incognito Mode at any time to prevent local browser storage from caching recent session titles or conversation histories.
