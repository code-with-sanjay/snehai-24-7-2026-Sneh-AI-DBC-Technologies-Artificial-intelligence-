Snèh AI Platform Documentation

Complete documentation for operating Snèh AI on web and mobile devices.

1. Model Selection Capsule

Use the model selector button in the bottom input bar to switch between fast conversational streaming models and reasoning-focused setups depending on your query needs.

2. Live Web Search Grounding

Click the Globe icon next to the send button to toggle real-time internet search. This allows Snèh AI to fetch live facts and include URL citations.

3. Code Formatting & PDF Export

All code blocks returned by Snèh AI feature syntax highlighting. Click the copy icon to copy code directly, or use the export action to generate formatted PDF documents.
