Security Infrastructure

Security specifications and data handling standards for Snèh AI by DBC Technologies.

1. TLS 1.3 Transport Encryption

All data exchanged between your browser and Snèh AI servers is encrypted in transit using industry-standard TLS 1.3 protocols, preventing eavesdropping or middle-tier interception.

2. Volatile Session Buffer Wiping

System prompts and user messages are loaded exclusively in volatile server RAM during response generation. Memory buffers are explicitly cleared upon completion of the streaming connection.

3. Cloud Infrastructure

Hosted on secure edge network nodes (Narwana Cloud Grid), Snèh AI uses multi-layered Web Application Firewalls (WAF) to mitigate DDoS attacks and unauthorized automated access.
